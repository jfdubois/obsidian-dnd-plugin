# Obsidian D&D Character Plugin Workspace

This repository contains the development workspace for:

- The Obsidian D&D character plugin
- The normalized 5eTools catalog builder
- The catalog HTTP service
- Shared data contracts
- The character rules engine
- Automated tests and project documentation

## Main project

Project instructions and documentation are located in:

`obsidian-dnd-character/`

## Local-only directories

The following directories are not committed:

- `external/`
- `runtime/`
- `test-vaults/`
